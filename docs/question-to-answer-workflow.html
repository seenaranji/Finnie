Finnie request flow

What happens between a user pressing Enter in the chat and the answer appearing, including every point where the turn can stop early.

step that may call a model fixed reply, no model call multi-agent path

Checks done in code, not by the model

Answer quality

Retrieval gate (no passages means no model call). Citation ids must have been retrieved. Advice-phrase scan replaces a leaking answer with a fixed redirect.

Numbers

Prices, statistics, portfolio metrics and goal scenarios are computed in Python. The model may only quote them from a METRICS block or tool result.

Untrusted text

News items that look like instructions are quarantined. Output must cite real items and may only contain links the articles supplied, or a code-built headline list replaces it.

Merging

The merged answer is rejected if it adds numbers, citation markers, links or unsupported sentences. The code-built version is used instead and the missing-parts note is always written by code.
